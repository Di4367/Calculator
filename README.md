# Calculator
A simple and interactive Python script that generates secure passwords based on user-defined criteria. This project is a great example of how Python can be used for randomization and basic string manipulation.

💡Features
-Lets users customize: Number of letters
-Number of symbols
-Number of numbers
-Generates a random, secure password
-Shuffles the characters to ensure unpredictability
-Clean, beginner-friendly logic using loops and lists

-->Technologies Used
-Python 3, random module for randomness
